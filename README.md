# Caesar Cipher (Java)

A Java command-line tool that encrypts and decrypts text using the Caesar cipher, a basic substitution cipher.

## Features
- Encrypt and decrypt text with any shift value
- Handles uppercase and lowercase letters
- Leaves numbers and symbols unchanged
- Validates user input

## How to run
1. Install Java (JDK)
2. Compile: javac CaesarCipher.java
3. Run: java CaesarCipher

## What I learned
- Java methods, loops, and string handling
- How substitution ciphers work
- Basics of encryption and why the Caesar cipher is easy to break
